# FC 안양 댓글 추첨기 ☕

에펨코리아 글 [오늘 안양 승리시 메가커피 아아 3명](https://www.fmkorea.com/10351544409)에
`안양만세`를 댓글로 단 사람 중에서 당첨자를 뽑는 페이지입니다.

**페이지:** https://goormigrm.github.io/fm-coffee/

## 참여 기준

- 댓글 중 하나라도 `안양만세`(또는 `안양만만세`)가 들어 있으면 참여 (띄어쓰기는 무시)
- 같은 사람이 여러 번 댓글을 달아도 한 번만 들어감
- 글 작성자(차짬)는 제외

## 사용법

1. 페이지를 열면 에펨코리아 댓글을 자동으로 불러와 명단을 채웁니다. 추첨 직전에 **새로고침**을 한 번 눌러 주세요.
2. 명단은 직접 고칠 수 있습니다 (쉼표로 구분).
3. 당첨 인원을 고르고 **추첨**을 누르면 당첨자가 한 명씩 나타납니다.

자동 불러오기가 안 되면 에펨코리아 글에서 댓글 영역을 복사해
**댓글 직접 붙여넣기**에 넣고 **명단 만들기**를 누르면 됩니다.

추첨은 브라우저의 `crypto.getRandomValues`를 사용합니다.
