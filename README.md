# FC 안양 댓글 추첨기 ☕

에펨코리아 글에 특정 문구(기본값 `안양만세`)를 댓글로 단 사람 중에서 당첨자를 뽑는 페이지입니다.

**페이지:** https://goormigrm.github.io/fm-coffee/

## 참여 기준

- 댓글 중 하나라도 필터 문구가 들어 있으면 참여
  - 띄어쓰기와 연달아 반복된 글자는 무시 (`안양 만세`, `안양만만세` → 인정 / `안앙만세` → 제외)
  - 쉼표로 여러 문구를 넣을 수 있고, 비워 두면 댓글 단 사람 모두 참여
- 같은 사람이 여러 번 댓글을 달아도 한 번만 들어감
- 글 작성자와 `제외할 닉네임`(기본값 `차짬`)은 제외

## 사용법

1. 페이지를 열면 에펨코리아 댓글을 자동으로 불러와 명단을 채웁니다. 추첨 직전에 **새로고침**을 한 번 눌러 주세요.
2. 다른 글로 추첨하려면 제목 아래 **설정 변경**에서 게시글 주소·필터 문구·제외할 닉네임을 바꾸고 **적용하고 댓글 불러오기**를 누르세요.
   - 설정은 이 브라우저에 저장되고 주소창에도 반영됩니다 (`?post=글번호&kw=문구&ex=닉네임`). 그 링크를 그대로 공유하면 같은 설정으로 열립니다.
3. 명단은 직접 고칠 수 있습니다 (쉼표로 구분).
4. 당첨 인원을 고르고 **추첨**을 누르면 당첨자가 한 명씩 나타납니다.

## 추첨 영상 저장 (에펨코리아 업로드용)

PC 크롬에서 **녹화하며 추첨**을 누르고, 뜨는 창에서 **허용**(이 탭 공유)을 누르면
지금 탭을 녹화하면서 추첨하고, 끝나면 `추첨_날짜_시간.mp4`가 다운로드 폴더에 저장됩니다.
소리 없이 5~8초 정도, 수 MB 크기라 에펨코리아 첨부 제한(동영상 40MB, 소리 있으면 45초)에 걸리지 않습니다.

폰(화면 녹화를 지원하지 않는 브라우저)에서는 같은 버튼을 누르면 추첨 장면을 페이지가 직접 그려서
세로형 mp4(또는 webm)로 만듭니다. 영상 속 당첨자는 화면에서 뽑힌 당첨자와 같습니다(한 번 뽑은 결과를 둘 다 보여 줌).
끝나면 미리보기 아래 **영상 저장**, 또는 **공유 · 사진에 저장**(지원하는 폰)을 누르세요.

## 붙여넣기

자동 불러오기가 안 되면 에펨코리아 글에서 댓글 영역을 복사해
**댓글 직접 붙여넣기**에 넣고 **명단 만들기**를 누르면 됩니다.

추첨은 브라우저의 `crypto.getRandomValues`를 사용합니다.
